# تطبيق شاشة العرض (Android)

تطبيق أندرويد بسيط يعرض شاشة الطابور (`/display`) بملء الشاشة، ليُثبَّت على جهاز
الشاشة في صالة الانتظار بدل فتح المتصفح يدوياً في كل مرة.

التطبيق **غلاف** حول الصفحة نفسها ولا يكرّر منطقها: الشاشة تبقى مُولَّدة من الخادم،
وأي تعديل على تصميمها يظهر على الجهاز فوراً دون إعادة تثبيت التطبيق.

## ما الذي يضيفه فوق المتصفح

| | |
|---|---|
| **ملء شاشة كامل** | بلا شريط عنوان أو أزرار تنقّل، ووضع immersive دائم |
| **الشاشة لا تنطفئ** | `FLAG_KEEP_SCREEN_ON` — الشاشة الجدارية تبقى مضاءة |
| **الصوت يعمل بلا لمس** | المتصفح يمنع تشغيل الصوت تلقائياً حتى يلمس أحدهم الشاشة، والتطبيق يعطّل هذا الشرط |
| **نداء صوتي عربي** | WebView في أندرويد **لا يدعم** `speechSynthesis`، فالتطبيق يوجّه النداء إلى محرّك النطق في النظام |
| **HTTP على الشبكة المحلية** | أندرويد 9+ يحجب الاتصالات غير المشفّرة افتراضياً، والتطبيق يسمح بها للخادم المحلي |
| **إعادة اتصال تلقائية** | عند انقطاع الشبكة أو توقف الخادم يعيد المحاولة كل 8 ثوانٍ بلا تدخّل |
| **تشغيل تلقائي بعد الكهرباء** | يفتح نفسه بعد إقلاع الجهاز إثر انقطاع التيار |
| **زر رجوع معطّل** | لا يمكن الخروج من الشاشة بالخطأ |

## الحصول على ملف APK جاهز

لا حاجة لتثبيت أدوات تطوير. عند رفع أي تعديل على مجلد `android/` يبني GitHub
الملف تلقائياً:

1. افتح صفحة المستودع على GitHub ← تبويب **Actions**
2. اختر آخر تشغيل لـ **Build display APK**
3. من قسم **Artifacts** نزّل `shafak-queue-display-apk`
4. بداخله ملفان — استخدم `app-release.apk`

يمكن أيضاً تشغيل البناء يدوياً من **Actions ← Build display APK ← Run workflow**.

## التثبيت على جهاز الشاشة

1. انسخ `app-release.apk` إلى الجهاز (USB أو رابط تنزيل على الشبكة المحلية)
2. فعّل **مصادر غير معروفة / Install unknown apps** لتطبيق الملفات
3. ثبّت الملف وافتح التطبيق
4. أدخل عنوان الخادم، مثال: `192.168.1.10:5000`
   (يكفي العنوان والمنفذ — يُضاف `/display` تلقائياً)
5. اضغط **حفظ وعرض الشاشة**

**للعودة إلى الإعدادات لاحقاً**: اضغط ضغطة مطوّلة في أي مكان على الشاشة.

## النطق الصوتي العربي

يستخدم التطبيق محرّك النطق المثبّت على الجهاز. إن لم تكن حزمة الصوت العربية
مثبّتة سيقرأ النداء بصوت غير عربي أو لا يُسمع:

**الإعدادات ← النظام ← اللغات والإدخال ← إخراج النص المنطوق** ← ثبّت البيانات
العربية لمحرّك Google.

## البناء محلياً (اختياري)

يحتاج Android Studio أو Android SDK مع JDK 17:

```bash
cd android
./gradlew assembleRelease
# الناتج: app/build/outputs/apk/release/app-release.apk
```

## نقطة تحتاج متابعة

شاشة العرض محميّة بكلمة سر عامة (تُضبط من `/admin/settings`)، وتُطلب من جديد عند
كل تشغيل للتطبيق — وإدخالها بلوحة مفاتيح على شاشة جدارية غير عملي. الحل المقترح
لاحقاً: السماح بتمرير مفتاح الجهاز ضمن الرابط ليتخطّى التطبيق شاشة القفل تلقائياً.

## التوقيع

نسخة الإصدار موقّعة حالياً بمفتاح التطوير (debug key) لتكون قابلة للتثبيت مباشرة.
هذا كافٍ للتوزيع الداخلي عبر USB، لكن قبل أي نشر عام يجب استبداله بمفتاح حقيقي
في `app/build.gradle.kts`.
